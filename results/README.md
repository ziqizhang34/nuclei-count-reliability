# Results included in the repository

`per_seed/` contains the archived test-set evaluation CSV and training history for seeds 42, 123, and 2024.

`tables/` contains the regenerated paper tables and the image-level average across seeds.

`figures/` contains the three paper-style diagnostic figures generated by `nuclei-analyze`.

Model checkpoints and per-image probability/mask artifacts are intentionally excluded. They can be regenerated from the official dataset and the training/evaluation scripts.
